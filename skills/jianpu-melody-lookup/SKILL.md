# 简谱旋律查歌

> **自检门**：所有检索/评测脚本启动时先跑 `selfcheck`（已知答案用例）。不过就 `exit 3`，
> 不出结果。原因见 `selfcheck/selfcheck.py` 文件头：口径错一次就会**凭空造出"完全一致"的假命中**。
>
> **唯一 token 口径**：`jptok.py`。解析音符只许调它（`parse_token` / `seq` / `query` / `beat` /
> `recover_bars`），脚本里**不许再自带** token 正则 —— 白名单分叉曾经让全库带 `#` 的音整段消失。

## 什么时候用

用户给你一段**旋律**（不是歌词、不是歌名），想知道是哪首歌。典型说法：

- "这是哪首歌：`5 5 5 3 2 2 3 5`"
- "哼一句查歌"、"识别这段旋律"、"帮我认认这个曲子"
- "下一句是 `3 2 1 1 6 1 2 6 5 5`，接的是哪首"

**不适用**：给歌名找谱、给歌词找歌（这个库里没有歌词）、识别五线谱图片。

## 怎么用

```bash
python lookup.py 51223323323531                    # 一段
python lookup.py "5 1 2 2 3 3 2 3 3 2 3 5 3 1"     # 带空格也行
python lookup.py 512233 6675 --top 5               # 多段一起查(分数相加, 更准)
python lookup.py 512233 --json                     # 给程序读
```

输入只认 `1`–`7`（简谱唱名）；`,6` 低八度、`'1` 高八度、其余字符忽略。**至少 5 个音**。

输出按"最小错音数"排序，每行给：错音数、**八度差异**、曲名、status、出处(`站点-id`)。

## 怎么解读结果（重要）

1. **看错音数**：0 = 完全命中；1–2 在长片段上仍很可能是对的；≥3 基本是乱猜。
2. **看八度差异**：主排序**故意忽略八度**（为了宽容哼唱），所以并列时看这一列。
   经典案例：《水手》与《爱上草原的小河》共享同一段 13 音，只差末两音的低八度
   （`,7 ,6` vs `7 6`）——错音都是 0，靠八度差异分开。
3. **并列就是"片段不够独特"**，不是工具坏了。换更长的片段、或补上中间那句，
   让"段段都接近"的歌胜出。多段查询就是干这个的。
4. **status**：`ok` = 人工校对过（可信度高）；`ocr` = 由图片机器转写（可能有辨认错误，
   错音数因此可能不为 0）。

## 指标（实测，不是宣称）

> **可复现性（2026-09-29 修）**：这些数都是"同一口径谁跑都一样"的。以前不是 ——
> `eval_golden.py` 全局只建一条随机流，于是"这次还问了哪几行"会改变后面几行抽到的片段：
> 同一份语料 `--lens 15 --errs 0` 得到酷狗 15 音 Top-1 **100.0%**，而 `--lens 11,15 --errs 0,1`
> 里同一格是 **97.7%**。现在每行 `(L,k)` 一条独立流（`seed + L*1000 + k`），两种问法给出同一个数。
> **旧文章里那些差 2~4 个百分点的数，都是那次调用恰好抽到那批片段的结果。**

### 一、四份**榜单**上的"能不能查到"（这就是"识别准确率"那句话的出处）

2026-09-29 在 **10,544 首**语料上实测（`eval_golden.py --list train-work/eval_set_*.tsv --lens 11,15 --errs 0,1`；
复现记录 `train-work/metrics_10544_stable.txt`）：

| 榜单 | 榜上 | 库里能定位 | 库内 **11 音 0 错 Top-1** | 库内 **15 音 0 错 Top-1** |
|---|---|---|---|---|
| 酷狗 2025 华流 Top100 | 98 | **87 = 88.8%** | **92.0%**（Top-3 96.6%） | **95.4%**（Top-3 100%） |
| 中文流行 100 经典 | 124 | 112 = 90.3% | 89.3%（Top-3 92.9%） | 97.3%（Top-3 100%） |
| 华语金曲奖 30年30歌 | 30 | **30 = 100%** | 86.7%（Top-3 96.7%） | **100%** |
| 腾讯音乐榜 2024 年度十大 | 10 | 2 = 20.0% | 100%（n=2） | 100%（n=2） |

> 同一批语料在 2026-09-28 深夜（10,153 首）是 84.7% / 90.3% / 100% / 10%：
> 酷狗那 **+4 首**（《爱错》《暮色回响》《爱情讯息》等）与腾讯 **+1 首**来自
> **多页谱修复**（见 `jianpu-db/misc/records/多页谱只转了一页_20260929.md`）——
> 旧管线一个目录只转**一张**页，多页谱的成品是半首甚至"和弦谱那页"。
> 腾讯榜 8 首缺口是**2024 新歌在这些简谱站上根本没有**（实测：按曲名把 jianpucn/jianpujia/jp114
> 三个站都翻了一遍，8 首全部 0 命中），属于**图源天花板**，不是检索问题。
>
> **前端与离线一致**：把 Python 侧真实用过的查询片段（`--dump-queries` 导出）在浏览器那份
> `static/search.js` 里重放，酷狗 15 音 86/87 = 98.9% Top-1 完全相同（那 1 条是同一首歌的两个
> 版本名，两边都是代价 0）、中文流行 111/112 = 99.1%；"期望曲名进 Top-3"两边都是 100%。

### 二、华流金曲清单（319 首）上的检索精度

按**曲名**判定是否召回；**2026-09-29 在 10,544 首语料上重测**
（清单里能在库中定位到 **289** 首，其中 **167** 首有 ≥2 个版本）：

| 片段长度 | 哼错音 | Top-1 | Top-3 | Top-5 |
|---|---|---|---|---|
| 11 音 | 0 | **91.7%** | 97.6% | 99.3% |
| 11 音 | 1 | 66.4% | 86.5% | 92.7% |
| 15 音 | 0 | **96.9%** | 99.7% | 100% |
| 15 音 | 1 | 95.1% | 100% | 100% |

更严的口径（**留一版本**：把查询所用的那份谱从索引里删掉，只能靠"同一首歌的另一个版本"命中，
模拟"没有原谱、纯凭记忆"）：11 音 0 错 Top-1 **41.3%**、15 音 **46.1%**（167 首多版本歌上测）。
两者差距说明：**片段检索的瓶颈是"片段是否唯一"，不是匹配算法**。

复现：`python eval_golden.py`（金曲口径，默认就是这份清单）、`python eval_metric.py`（随机留一口径，口径说明见文件头）。

> 上一版这张表是 10153 首时代测的（11 音 0 错 91.7% / 15 音 98.3%、可定位 289 首）；
> 再上一版是 8926 首时代（90.1% / 98.2%、可定位 283 首），再往前是 7385 首时代（94.4% / 98.1%）。
> 四版都是**实测**：可定位数随语料涨，11 音的 Top-1 在 90~94% 之间小幅摆动
> （库越大干扰越多、但金曲覆盖也越多）。
> 逐条漏报的归因见 `jianpu-db/misc/records/检索漏报逐条_20260928.md`：
> 前五名全落空的那两条都是**退化片段**（11 个音里 10 个同音/全同音），不是检索失败。

## 文件

| 文件 | 作用 |
|---|---|
| `lookup.py` | 查询入口，自包含（只依赖 `data.jsonl` + numpy） |
| `lookup_acc.py` | **升降号感知**的查询（发送从严、接收从宽：输 `5` 能中 `#5`，输 `#5` 更精确） |
| `lookup_norm.py` | 归一化口径的查询（不计升降号，只比音级） |
| `jptok.py` | **唯一** token 解析/时值/小节线实现 |
| `gate.py` / `selfcheck/` | 自检门：已知答案用例 |
| `show_hit.py` / `check_hit.py` | 把库里命中那一段原样摊开（带记号） |
| `show_song.py` | 把一首谱**按小节**分段打出来（`show_song.py 神々`），便于人工圈定是哪一段 |
| `data.jsonl` | 数据集本体：10191 首（= HuggingFace `Caesium-132/chinese-jianpu-corpus`）；自检门会核对它是否与 `jianpu-db/data.jsonl` 同步 |
| `eval_golden.py` | 金曲清单指标 |
| `eval_metric.py` | 随机留一指标（含两种口径的定义） |

换数据集：`--data 别的.jsonl` 或环境变量 `JIANPU_DATA`。

## 记法（数据里 `score` 字段的含义）

- 音高 `1`–`7`；`,` 降八度、`'` 升八度（可叠：`''1`）
- 时值前缀 `q`=八分 `s`=十六分 `d`=三十二分 `h`=六十四分；**无前缀 = 四分**
- `.` 附点、`-` 延长一拍、`0` 休止、`x` 念白、`~` 连音线、`3[ … ]` 三连音
- **本库不含歌词**：这是纯旋律语料，别拿歌词来查。
